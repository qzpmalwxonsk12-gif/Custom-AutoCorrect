Personal Autocorrect

Everything runs on this device. No text is sent anywhere, and there is no cloud or AI component in this build.

Getting started

  1. Open a page with a text box.
  2. Click the extension icon and choose Enable on this site.
  3. Type waht — it becomes what.
  4. Open the correction panel to review, revert, and teach it.

Writing profile

A profile is a named set of thresholds and rule modes suited to one kind of writing. Choosing one is an explicit decision, so it overrides the sliders below.

Per-website profiles

Rule controls

Every rule can run automatically, only offer a suggestion, or be switched off. These override the profile. “Default” means the setting elsewhere on this page decides.

Shadow mode

In shadow mode providers analyse your text and record what they would have done, without changing anything. Use it to judge a rule before trusting it.

Personal vocabulary

Words, names, phrases and replacements you have decided about. Each entry has a scope, so “leave this alone here” never becomes “leave this alone everywhere”.

Appearance & accessibility

Diagnostics

A private status page for this device. It contains no text you have typed.

Corrections

Essential punctuation

A deterministic, offline rule engine that inserts punctuation only when sentence structure makes it unambiguous. It runs when you pause typing, never on every keystroke, and every change is reversible from the correction panel.

Harper grammar engine

Harper is an ~18 MB WebAssembly engine that runs entirely inside the extension. Findings appear as suggestion chips after you pause typing — it never rewrites text automatically and never runs on the keystroke path. Its spelling checks are suppressed; the built-in spelling engine owns those.

Each automatic fix shows a fading before/after badge with an Undo button, and is recorded in the correction panel like any other change. Subjective rules (style and readability), rules measured as unreliable, and any rule you have reverted twice without keeping it stay suggestion-only even with this on.
