What to try in the panel

  1. Click the icon → Open correction panel.
  2. Click any entry — the page scrolls to it and highlights it, and a card shows waht → what.
  3. Reject & revert on one of two identical corrections; only that occurrence should change back.
  4. Review N corrections → walk the queue with the arrow keys while the panel has focus.
  5. Revert something with Never this replacement, then type the same typo again — it should stay uncorrected.
  6. Reload the page. The history should still be there (unless you turned persistence off in Settings).
